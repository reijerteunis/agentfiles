# Offer negotiation

Most people accept the first number. A calm, well-prepared counter is expected, rarely costs an offer, and compounds for years. Prepare it properly.

This skill organises the decision and the conversation. It isn't legal, tax or financial advice. Contract clauses (non-compete, IP, termination) belong with an employment lawyer, and equity taxation with a tax advisor. Say so in the output.

## Break the offer down

Write `offer.md` with a table per offer:

| Component | Offer | Notes |
|---|---|---|
| Base salary | | |
| Bonus | target %, how it's paid out, guaranteed or not | |
| Equity | type (options, RSUs, phantom), number, strike price, latest valuation, vesting and cliff, acceleration, exercise window | |
| Benefits | pension, holiday, health, learning budget, equipment | |
| Title, scope, reports to | | |
| Location and remote policy | | |
| Start date and notice | | |
| Restrictive clauses | non-compete, non-solicit, IP assignment | **lawyer review** |

Ask for anything that's missing; never assume a number. Compare like for like: Dutch salaries are often quoted without the 8% holiday allowance (vakantiegeld) or a 13th month, and pension contributions differ a lot between employers.

## Evaluate

- Compare it with the floor and target in `profile/preferences.md`, and with other offers side by side.
- Value the equity in three scenarios (zero, a modest exit, a strong exit), stating every assumption. Treat private-company equity as uncertain.
- Gather market data from cited, recent sources for the role, level and location, and say how reliable it is.
- Weigh the non-money factors the person cares about, using the weights from preferences.

## The plan

1. **The asks,** ranked: usually base or a sign-on first, then equity, then title, scope and start date. Pick 2–3, not 10.
2. **The anchor:** one number per ask, justified by market data and by the person's value (the angle), never by personal need.
3. **Trade-offs** to offer if they push back (start date, a review after 6 months, a sign-on bonus instead of base).
4. **The walk-away point,** taken from preferences, and what to say if they reach it.
5. **Scripts:** a call opener, the counter email, and replies to "this is our best offer" and "what are your expectations?". Keep them warm and specific, and never ultimatums.
6. **Timeline:** when to respond, and how to handle an exploding deadline.

## Rules

- Never share the current salary or other offers' details unless the person decides to. Never bluff about an offer that doesn't exist.
- Get the final agreement in writing before resigning anywhere.
- Drafts only. The person has the conversation and sends the emails.
