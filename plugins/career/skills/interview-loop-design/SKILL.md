# Interview loop design

Unstructured interviews mostly measure how much an interviewer liked the candidate. A structured loop measures each competency once, with a written rubric, by someone trained to assess it. The result is a better hire, made faster and more fairly.

## Steps

1. **Scorecard.** From the job description's outcomes, define 4–6 competencies, for example "designs systems for 10x load", "builds and grows teams", "makes decisions with incomplete data". Each competency gets a definition and what great looks like in this role.
2. **Stages.** Assign each competency to exactly one stage. A typical leadership loop:

   | Stage | Duration | Assesses |
   |---|---|---|
   | Recruiter screen | 30 min | motivation, logistics, range |
   | Hiring manager | 60 min | depth, judgment, the top must-have |
   | Technical / architecture | 60–90 min | system design, trade-offs |
   | Leadership and collaboration | 60 min | team building, conflict, influence |
   | Final / founder | 45 min | strategy, values, mutual fit |

   A role below senior usually skips the founder stage and keeps a practical exercise.
3. **Questions.** For each stage, write 3–5 questions: behavioural ("tell me about a time…") for track record, situational ("how would you…") for judgment, and a work sample for skill. Add follow-up probes for each.
4. **Rubrics.** Score each competency from 1 to 4, with an anchored description of each level. Give examples of the evidence a 2 and a 4 would show. "Seemed smart" is not evidence.
5. **Take-home policy.** Make it optional or paid, cap it at 3–4 hours, review it against a rubric written in advance, and discuss it in the next stage.
6. **Decision rules.**
   - Every interviewer submits written feedback before any discussion.
   - The hiring manager decides; the debrief informs.
   - A strong no on a must-have is a no.
7. **Candidate experience.** Decide within five working days of the final stage. Tell candidates the stages up front, and give rejected finalists real feedback.

## Output

Write `interview-loop.md` containing the scorecard, the stage table, the questions per stage with probes, the rubrics, the decision rules, and a feedback form template interviewers can copy. Train interviewers on the rubric before the first candidate.
